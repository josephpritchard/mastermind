This is my first personal project for boot.dev's DevOps track.

It is a Mastermind solver.

You can do the basic six colors or go up to ten.

It displays each guess with the determined amount of possible solutions.

It uses the minimax algorithm, which I coded based off of the concepts as AI explained them to me.

I only vibe-coded the while loop in setup.py that gets the input from the user for color entries.

It takes three or four guesses with six colors (1296 possible solutions), and up to five or six guesses with ten colors (10,000 possible solutions).
